Licenses and rights

Licenses

The dataset is planned for CC BY 4.0, the model for Apache-2.0, and the website code and tools for MIT. Voice and publicity rights are handled in the consent form, separately from copyright.

Dataset: Creative Commons Attribution 4.0

Decided November 15, 2026. The recordings, transcripts, and metadata are planned for release under CC BY 4.0.

Anyone may copy, adapt, and reuse the dataset for any purpose, including commercially, if they give attribution. The project asks that credit go in the dataset or model card and in docs — not inside each generated audio clip. That is treated as reasonable attribution under CC BY 4.0 section 3(a)(2).

Credit line (use this exactly, once the contributors URL exists):

OpenSanta Dataset by OpenSanta contributors (contributors URL coming soon), licensed under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).

The full explanation, including the dataset notice draft, is in the dataset license notes (printable version).

Model license: Apache-2.0

Decided November 17, 2026. The trained voice and weights are planned for release under the Apache License 2.0, an OSI-approved open-source license. Anyone may use, modify, and redistribute them, including commercially, if they keep the license and notice files.

The trained voice will still be a derivative of whatever base TTS model we fine-tune, so that base license can limit what we ship. We will only shortlist base models that allow commercial use and redistribution of fine-tuned weights under Apache-2.0 or a compatible license.

Apache-2.0 does not add use restrictions. A short, non-binding responsible-use guideline asks people not to impersonate real people, not to use the voice for scams, and not to harass anyone. Those requests are not license conditions. See the model license notes (printable version).

Voice and publicity rights

CC BY 4.0 covers copyright only. It does not license personality or publicity rights (section 2(b)(1)). The consent form (printable version) grants voice and publicity permissions separately, so the recordings and the model can be used as the project describes.

The script

Most of the 100 lines in the recording script were written fresh for this project and will be released with the dataset under CC BY 4.0. Eight lines are from the 1823 public-domain poem “A Visit from St. Nicholas.” See the recording script notes (printable version).
